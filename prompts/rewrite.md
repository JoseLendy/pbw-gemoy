# 阶段 8 修订：定点重写（rewrite）

核验发现了问题。你只修改出问题的字段，其余字段原样保留。

## 输入
- 出问题的字段及当前内容
- 问题说明（核验代码给出的中文原因、涉及的原文片段）
- 与写作阶段相同的约束：已选事实、表达边界、图片方案、平台规则

## 规则
- 只输出需要修改的字段，没有问题的字段不要出现在输出里。
- 不得新增任何事实。只能使用已选事实和背景事实的编号与原词原值。
- 问题是数字或说法无依据时：删掉或改成清单里有的说法。
- 问题是绝对化用语时：改写，上限类取值写成"可达""最多支持""支持"。
- 问题是价格、补贴、销量、奖项、评价、测试结果、政策承诺时：直接删除，不用别的说法替代。
- 问题是字数、结构、套话、图片数量时：按平台规则调整，仍然每句产品说法带 [F#]。

## 输出（只输出一个 JSON 对象，只含需要修改的字段）
```json
{"title": "", "intro": "", "body": [""], "cta": "", "tags": [""],
 "selling_points": ["F1"], "images": [{"media_id": "", "position": "", "caption": ""}]}
```
body 如需修改，请输出完整的 body 数组。
